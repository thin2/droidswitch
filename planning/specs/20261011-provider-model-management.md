# 供应商模型管理增量

## 目标与范围
供应商卡片直接获取模型、批量手动添加、查看该供应商模型。手动输入每行一个精确 API ID，预览去重与已有条目，保存草稿后仍需预览并应用。模型列表以小标签显示供应商，不改 API ID 或用户显示名。

## 关键决策
复用 import_models 原子草稿命令，同供应商去重、跨供应商允许相同 ID，保留已有参数。获取弹窗预选并锁定卡片供应商。查看模型通过 URL 筛选，支持返回与刷新。失败保留输入，最多单次 10000 个 ID。无付费生成请求。

## 后续边界
同名模型折叠分组留作后续；本轮保留独立连接条目及供应商标签，避免协议不同被误合并。Codex 代理仍只保留方案。配置冲突修复已有提交 a678671，本轮回归验证，不覆盖用户配置。

## 验收
供应商入口作用于正确连接；重复与已有 ID 不重复写入；跨供应商同 ID 可添加；获取失败可切换手动添加；查看模型筛选正确。前端构建、浏览器回归、Rust 批量导入及配置合并测试通过。Windows 真机测试由用户后续执行。
