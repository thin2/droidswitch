## 1. 概述

### 1.1 功能目标
一个本地桌面软件,集中管理中转站/API 凭据/模型,支持官方订阅与自定义 API 双向切换,并查看真实采集的模型用量。用户完成配置后在 Droid 的 `/model` 中自行选择模型。软件只负责**模型配置、导入、来源切换、用量统计**。

### 1.2 目标用户
使用 Factory Droid CLI、需要管理多个中转站/BYOK 供应商与模型、并希望在官方订阅和自定义 API 之间切换的开发者。

### 1.3 成功标准(首版)
在**受支持的目标 Droid 版本**上,用真实会话样本通过验收清单 A-01~A-10(见第 7 节)。不得用演示数据代替验收。

### 1.4 明确不在范围
任务分类、Agent 编排、Skills 编辑、聊天窗口、代码执行工作台;不代管 Factory 账号/订阅/额度;Factory 登录由 Droid 完成。

## 2. 功能需求

### 2.1 核心功能(首版必须实现)
1. **供应商与模型管理(文档 §4)**:供应商连接 CRUD、同站多连接;获取模型多选窗口;模型字段编辑(显示名/真实 ID/协议覆盖/启用/最大输出 Token/图片输入/高级参数);停用与删除、悬空引用检测;手动输入模型 ID。
2. **配置应用与凭据(文档 §5)**:默认目标 `~/.factory/settings.json` 可改;首次导入标"外部配置";非破坏式读取合并;变更预览(脱敏);原子写入(备份→临时文件→校验 JSON→替换);文件指纹冲突检测;重新载入不丢草稿;备份恢复;`${VAR}` 与直写两种凭据模式 + 全链路脱敏;不写管理字段进 customModels。
3. **官方订阅 / 自定义 API 切换(文档 §9)**:分段控件区分浏览/待应用/已应用;两套方案分别保存 modelSource + 最近有效模型 ID + 思考参数;官方页模型选择/刷新/前往登录;切换只生成目标版本支持的默认设置;不清空 customModels、不覆盖整份 settings.json、不改登录凭据、不自动开会员、不自动付费回退;子 Agent/Skills/Spec/Missions 显式模型不被覆盖;优先级提示。
4. **CC Switch 导入(文档 §10)**:入口在模型库顶部;定位数据目录(默认 `~/.cc-switch`)只读 + WAL 一致性读 `cc-switch.db`;向导(定位→选来源→检查→处理重复→导入草稿);导入 Claude Code/Codex 的 API 供应商与模型;路由占位/原生接口标"不支持直接导入";重复项识别不静默覆盖;读取失败明确提示;结果汇总;不导历史用量。
5. **连接测试(文档 §7)**:配置校验 / 模型列表获取测试 / 模型调用测试(用户点击触发、提示耗额度、不带项目代码、标鉴权/响应/延迟);延迟展示完整请求耗时 + 测试时间。
6. **基础用量统计(文档 §11-12)**:独立页;只读扫描 Droid 本地会话记录增量导入;稳定事件键去重、累计转增量、处理重放/轮转/重置/分支/重试;Token 口径归一(互斥、null≠0);API 费用估算(各类 Token × 单价,手动单价 + 币种);来源分别统计;明细切换(模型/供应商/使用记录)+ CSV 导出;只存统计元数据不删原始会话。
7. **界面与视觉(文档 §6/§13-15)**:三栏主界面;左导航 + 供应商筛选;顶部分段切换;底部固定变更条;视觉基线(暖白/陶土橙)+ 可访问性 + 响应式。

### 2.2 扩展功能(P3,后续)
深色主题(UI-12);流式与工具调用诊断(T-05);Factory Analytics API 补充源(U-12);成功率/延迟/官方剩余额度(U-13);供应商余额查询、可选本地代理采集(U-14)。

## 3. 技术规范

### 3.1 技术栈
Tauri 2 + React + TypeScript(前端);Rust(文件读写、原子替换、文件指纹、网络请求、只读 SQLite/WAL);SQLite(管理记录、草稿、统计事件、同步游标)。

### 3.2 架构设计
- **适配器层(集中版本差异)**:只把合并后的 Droid 支持字段写入目标配置;按目标 Droid 版本读写;不认识的版本优雅降级并提示。版本契约文档(阶段 0 产出)是其配置源。
- **三类 ID 物理分离**:应用内部 UUID、API 模型 ID、Droid 选择器 ID,严禁凭空拼 `custom:模型名`。
- **凭据边界**:`${VAR}` 引用(默认,不落盘明文)与直写(兼容模式,首次强提示);文件权限收紧;界面默认遮盖;日志/导出一律脱敏;预览只显示"密钥已更改"。

### 3.3 数据模型(SQLite)
- `ProviderConnection`:连接名、API 基础地址、默认协议(Anthropic Messages / OpenAI Responses / Chat Completions)、凭据方式、模型列表地址(可选)、附加请求头(可选、脱敏)。
- `ModelEntry`:内部 UUID、providerId、显示名、真实模型 ID、协议覆盖、enabled、最大输出 Token(可空)、图片输入、高级参数、最近测试结果。
- `ApplySnapshot`:应用快照 + 完整备份引用 + 文件指纹。
- 另:草稿、统计事件、同步游标、单价/币种设置。

### 3.4 协议映射
以官方 BYOK 文档为准(V-07 核对):Anthropic Messages / OpenAI Responses / OpenAI Chat Completions。

## 5. 非功能需求

### 5.1 可靠性(配置闭环核心)
原子写入 + 文件指纹冲突检测;写入失败/无效 JSON 不损坏原配置;重新载入不丢草稿。

### 5.2 安全
`${VAR}` 默认不落盘明文;直写兼容模式首次强提示;文件权限收紧;界面遮盖;日志/导出/截图无完整密钥;预览只显示"密钥已更改"。

### 5.3 平台
Windows + macOS;路径(`~/.factory`、`~/.cc-switch`)与权限两套实现;WebView2 / WKWebView UI 各回归一次。

## 6. 边界情况处理
- **配置冲突**:应用前外部改目标文件 → 中止旧草稿覆盖,提示重新载入/合并。
- **写入失败**:权限/格式/磁盘错误 → 原配置仍可用,保留草稿。
- **测试错误**:401/403、404/不支持、429、超时、不支持模型列表 → 分别给对应反馈,不自动误判余额不足,不自动反复重试。
- **切换失效**:目标模型失效/未登录/无权限 → 不静默切到其他计费来源,不把"写入成功"标为"可调用"。
- **导入异常**:重复不增殖、缺字段、同名不同密钥、路由占位、源库占用(WAL)、未知结构、取消 → 源文件不改、敏感值不入日志。
- **统计异常**:重复扫描不重复计数、累计转增量、缓存不重复、跨日时区、来源切换、缺单价、未知来源、分支重放、断点续采;null=未知不转 0。

## 7. 测试和验收

### 7.1 测试策略
- **适配器/解析器**:用阶段 0 实测产出的真实 settings.json 片段与日志样本做**夹具单测**,不必每次开真机。
- **配置闭环**:临时目录模拟 `.factory` 做集成测 + 故障注入(写一半中断、无效 JSON、磁盘满)。
- **真机验收**:A-01~A-10 逐条在受支持 Droid 版本签字,用固定会话样本与 Droid 可见用量核对。

### 7.2 验收标准(首版必须通过)
- **A-01 多供应商共存**:两家相同模型 ID,显示名可区分,应用后均可在 Droid 识别。
- **A-02 非破坏式同步**:改一个模型后,未知字段/未接管模型/其他设置语义不变;无变化不重复添加。
- **A-03 草稿一致性**:改开关/参数不立即写入;重启可恢复草稿;放弃更改回到已应用状态。
- **A-04 冲突保护**:应用前外部改目标文件,中止旧草稿覆盖并提示重新合并。
- **A-05 故障与恢复**:写入失败/无效 JSON 不损坏原配置;恢复备份后与选定快照一致。
- **A-06 凭据可用**:`${VAR}` 引用与直接写入分别在独立终端验证;截图/导出/日志无完整密钥。
- **A-07 真实集成**:Droid `/model` 核实同步模型及真实调用;关闭软件后配置仍可用。
- **A-08 切换往返**:"API→官方→API"两套选择与凭据不丢失,其他配置不变,新会话用预期来源,旧会话/显式覆盖有提示,无自动付费回退。
- **A-09 导入**:正常/重复不增殖/缺字段/同名不同密钥/路由占位/源库占用/未知版本/取消 — 源文件不改,敏感值不入日志。
- **A-10 统计**:重复扫描不重复计数/累计转增量/缓存不重复/跨日时区/来源切换/缺单价/未知来源/分支重放/断点续采 — 与 Droid 可见用量核对。

## 9. 风险和依赖
1. **版本契约脆弱(最高风险)**:产品依赖 Droid 未公开内部,升版可能变 → 适配器版本化 + 版本契约文档 + 优雅降级;首版只对实测过的版本打包票。
2. **实测环境缺 key**:需真实调用的验收(T-03、真实 token 落日志、官方额度)等 key 到位;其余"写配置→看行为"可先行。降级路线:先用假设 + 夹具开发内核,环境到位再闭环验收。
3. **用量日志不确定**:若 Droid 不落 token 明细(只累计或缺失),U-05/06 可能受限 → V-06 先探明,缺失以"未知"呈现不猜测。
4. **双平台 webview 差异**:Win/mac UI 各自回归。
5. **凭据可用性误解**:必须在 UI 讲清 `${VAR}` 仅对设置了该变量的终端有效。
