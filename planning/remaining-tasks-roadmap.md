### 阶段 4: P2 路由功能（可选，2-3 周）

**决策点**: 是否在首版中包含官方订阅路由功能？

#### 方案 A: 首版不包含（推荐）
- **优势**: 快速发布，降低复杂度，专注核心 API 管理
- **策略**: v0.1.0 只做 API 模型管理，v0.2.0 再加路由
- **时间节省**: ~13-23 个工作日

#### 方案 B: 首版包含完整路由
- **优势**: 功能更完整，官方订阅 + API 双支持
- **成本**: 需要 #050-#058 全部完成（13-23 日）
- **风险**:
  - OAuth/OIDC 集成复杂度高
  - 本地路由服务稳定性需要验证
  - 跨平台兼容性测试增加

**建议**: 采用方案 A，分阶段发布
